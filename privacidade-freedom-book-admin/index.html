Freedom Book Admin
Privacidade e Google OAuth

Política de Privacidade

Esta política descreve como o Freedom Book Admin trata dados quando o proprietário do aplicativo autoriza acesso ao Google Search Console. O Freedom Book Admin é um console operacional privado da Freedom Book, usado para administrar e analisar o site achadostube.com.br.

1. Dados acessados

O aplicativo solicita exclusivamente o escopo Google Search Console de leitura webmasters.readonly. A sincronização consulta dados de desempenho de propriedades do Search Console que a conta autorizada tem permissão para visualizar.

Os registros utilizados pelo painel podem incluir:

  • data;
  • consulta de pesquisa;
  • URL/página;
  • cliques;
  • impressões;
  • CTR;
  • posição média.

2. Finalidade

Esses dados são usados somente para análise interna de SEO e operação editorial, incluindo comparação de períodos, identificação de oportunidades, avaliação de experimentos, detecção de quedas ou crescimento e priorização das próximas ações no Freedom Book Admin.

O aplicativo não usa o acesso ao Search Console para publicar conteúdo, alterar propriedades, executar campanhas publicitárias ou modificar configurações da Conta Google.

3. Armazenamento e segurança

Os dados sincronizados ficam em infraestrutura privada do projeto administrativo no Netlify. O painel público da Freedom Book não recebe esses dados.

  • Credenciais OAuth são mantidas como variáveis secretas do ambiente de produção e não são gravadas no repositório público.
  • O snapshot de Search Console armazenado pelo sistema contém apenas o período atual e o período-base mais recentes.
  • Uma nova sincronização substitui o snapshot anterior.
  • O audit trail registra metadados operacionais da sincronização, como data final e quantidade de linhas, e não armazena tokens OAuth.
  • O audit trail é limitado aos 200 eventos operacionais mais recentes.

4. Compartilhamento

Os dados do Google Search Console não são vendidos, alugados ou usados para publicidade direcionada. Eles não são disponibilizados publicamente. O tratamento ocorre somente pelos serviços técnicos necessários ao funcionamento do aplicativo, como Google APIs e a infraestrutura privada de hospedagem/armazenamento do Netlify, além de eventual obrigação legal aplicável.

5. Acesso e controle

O console administrativo é restrito a usuários autorizados da equipe. O proprietário da Conta Google pode revogar a autorização do aplicativo a qualquer momento nas configurações de segurança/permissões da própria Conta Google. A remoção das credenciais do ambiente privado também interrompe novas sincronizações.

6. Retenção

O Freedom Book Admin mantém somente o snapshot mais recente de desempenho necessário ao funcionamento do painel. Esse snapshot é substituído a cada sincronização. Metadados do audit trail ficam limitados aos 200 eventos mais recentes. Credenciais permanecem configuradas somente enquanto o proprietário desejar manter a integração ativa.

7. Uso de dados das APIs do Google

O uso e a transferência de informações recebidas das APIs do Google pelo Freedom Book Admin obedecem à Google API Services User Data Policy, incluindo os requisitos de Limited Use quando aplicáveis.

8. Alterações nesta política

Esta política pode ser atualizada quando o comportamento real do aplicativo mudar, por exemplo se novos tipos de dados, novos provedores ou novos fluxos de armazenamento forem adicionados. Mudanças relevantes serão refletidas nesta página antes de serem consideradas parte do fluxo operacional.

9. Contato

Questões sobre o uso de dados do Google podem ser encaminhadas ao endereço de suporte informado na tela de consentimento OAuth do Freedom Book Admin.
