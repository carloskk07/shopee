# Freedom Book — Monetization Control Plane v1

Apoio LivePix está ativo. Premium e afiliados ficam inativos até existir produto/link real. A camada é progressiva, no máximo dois blocos, nunca antes do conteúdo, nunca perto de download de PDF, sem popups/interstitials/autoplay/scripts de terceiros. Links afiliados futuros exigem `rel="sponsored noopener noreferrer"`, disclosure e justificativa editorial original. Para ativar uma oferta, editar somente `monetization.json`, validar, atualizar hashes, abrir PR e aguardar CI + smoke.
